# Different Articles

You can log in/sign in and navigate between four categories in the navigation bar.  
You can view news articles, sport articles, and fashion articles.

A subscription on a special channel is available. It includes many amazing articles from the most popular magazines in the world.

There are three types of users:
- Ordinary user — can see ordinary articles.
- Premium user — can see all articles (same as admin).
- Admin — can see and edit all articles.

All users can comment on articles and save them into the "Saved articles" list.

If you are subscribed to a channel, you will also receive notifications when a new article is published in that channel.

---

### Install dependencies
```bash
pip install -r requirements.txt
```


### Start frontend
```bash
cd kursova2/kursova/frontend
npm start
```


### Start backend
```bash
cd kursova2/kursova
python manage.py runserver
```
